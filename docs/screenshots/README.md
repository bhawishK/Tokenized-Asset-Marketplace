# App screenshots

Captured on 2026-11-18 from the actual Expo web app using an isolated browser session with a **430 x 1000 CSS-pixel viewport**, light appearance and device scale factor 2. These are phone-sized web captures, not native iPhone screenshots.

| File | State |
| --- | --- |
| `buy-gold.png` | Buy Gold before the sample purchase: illustrative 250 MockUSD balance and 100 DemoGold inventory. |
| `review.png` | Sample purchase review: pay 100 MockUSD, receive 1 DemoGold. |
| `portfolio.png` | After selecting Run sample purchase: illustrative 150 MockUSD and 1 DemoGold, plus session-only purchase activity. |
| `account.png` | Account, disconnected wallet and Testnet gas guidance; sample mode remains active. |

The app was navigated through Account > Try sample mode, Buy Gold > Review purchase > Run sample purchase, then Portfolio and Account. No wallet was connected, no signature was requested and no transaction was submitted for these captures. The visible sample labels must remain when reusing them. These images are not proof of chain balances or atomic settlement.
